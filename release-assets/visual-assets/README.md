## Production Notes

### For Screenshots
- Use clean browser (no extensions visible)
- Clear any personal data
- Use representative content
- Capture at 2x resolution for retina

### For Infographics
- Ensure data accuracy
- Include source attribution
- Make accessible (alt text, color contrast)

### For Social Graphics
- Test on each platform
- Check text legibility
- Verify no cropping issues
