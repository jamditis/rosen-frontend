Google Sheets / SFTP credentials**, so the normal `backend/src/rosen_scraper/workflow.py`
and Pillar-3a (`process_submission.py`) enrichment path could not run. By
operator decision, enrichment fields (summary, thematic_categories,
key_concepts, era, scope, pull_quote, and the entity/relationship graph) were
generated by Claude in-environment instead of Gemini. Full article text for

## Method

1. **Discovery** — PressThink RSS (`/feed/`) + homepage + `/2026/` archive; web
   search for 2026 interviews/podcasts/essays by and about Rosen; Bluesky public
   API for the post gap.
2. **Ingestion** — schema-aligned rows appended to `archive_records-public.csv`,
   `social_posts.csv`, `extracted_entities.csv`, `extracted_relationships.csv`
   (CRLF line endings, additive only).
3. **Regeneration** — `node data/export-archive-data.js` rebuilt the split JSON,
   16 RSS feeds, and OPML.
4. **Validation** — `npm test`: 530 pass / 0 fail, including the `#207`
   extraction-coverage invariant (satisfied by the new relationships).
