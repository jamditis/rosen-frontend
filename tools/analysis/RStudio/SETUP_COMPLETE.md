## 🚀 Quick Start

### For RStudio Users (5 minutes):

1. **Open RStudio**

2. **Set working directory:**
   ```r
   setwd("C:/Users/amdit/OneDrive/Desktop/Crimes/playground/rosen-scraper/RStudio/scripts")
   ```

3. **Install packages (first time only):**
   ```r
   install.packages(c("googlesheets4", "dplyr", "ggplot2", "tidyr"))
   ```

4. **Load data:**
   ```r
   source("load_data.R")
   ```

5. **Run analysis:**
   ```r
   source("jay_rosen_analysis.R")
   ```

**For detailed instructions:** See `docs/QUICK_START_R.md`

1. **`load_data.R`** - Load data from Google Sheets (run this first!)

   - Entity type distribution
   - Top mentions by type

   - Entity type distribution chart

   - Custom filtered searches
