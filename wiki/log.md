# Change log

History of changes to this bundle, newest first.

## 2026-06-23

- **Flight recorder** — Added [`meta/bundle-inventory.md`](meta/bundle-inventory.md) and [`meta/bundle-inventory.json`](meta/bundle-inventory.json), generated by `npm run okf:flight-recorder`, to snapshot concept inventory, local graph policy, freshness badges, drift risk, and orphaned concepts.
- **Blindfold test** — Added [`meta/blindfold-test.md`](meta/blindfold-test.md) and scenario data in [`meta/blindfold-scenarios.json`](meta/blindfold-scenarios.json), generated by `npm run okf:blindfold`, so a new reader's path from `wiki/index.md` is tested against real project questions.
- **Wiki UX requirements** — Added [`meta/wiki-ux-requirements.md`](meta/wiki-ux-requirements.md) and updated the public `#wiki` plan so local graph navigation and per-concept freshness badges are requirements, not visual extras.
- **Enhancement radar** — Added [`meta/enhancement-radar.md`](meta/enhancement-radar.md) from parallel explorer scans, preserving next-step ideas such as profile fixtures, inventory diffs, renderer label policy, and a public/internal bridge sample.
- **Operator map** — Added project workflow, CI/testing, cache/versioning, maintenance automation, data-quality gaps, launch/open-decision, and re-verification concepts. These pages turn the bundle from a launch summary into a working map for future repo sessions.
- **Public wiki distinction** — Added [`systems/public-community-wiki.md`](systems/public-community-wiki.md) and a README note clarifying that this `wiki/` directory is the internal OKF bundle, while the public Archive wiki is the in-app `#wiki` route backed by `data/wiki-seed.json`.
- **Indexes** — Wired the new concepts into the `project`, `systems`, `data`, `launch`, and `sources` indexes, and expanded the root map to cover operations and verification.
- **OKF profile and validator** — Added [`meta/`](meta/index.md) with a reusable project-wiki profile, templates, adoption playbook, and quality model; added `scripts/validate-okf.js`, `tests/okf-bundle.test.js`, `npm run test:okf`, and CI wiring so wiki structure is checked with the repo.
- **Community roadmap** — Added [`meta/community-roadmap.md`](meta/community-roadmap.md) to identify concrete ways this repo can contribute patterns back to the wider OKF and open-knowledge community without presenting local conventions as universal rules.
